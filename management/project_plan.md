# Организация учебного проекта

## Участники

- Мазунина Карина — оформление требований и описание работы приложения.
- Быкова Анна — подготовка тестовых примеров и проверка документации.

## Этапы работы

1. Согласовать, какие возможности будут у приложения.
2. Записать требования и порядок перевода.
3. Подготовить тестовые ситуации.
4. Проверить документы и внести изменения.
5. Сохранить итоговые материалы в Git-репозитории.

## Простые правила работы

- Перед началом работы получить свежие изменения из репозитория.
- Перед редактированием сообщить напарнице, какой файл меняется.
- Стараться не менять один и тот же файл одновременно.
- После законченной задачи сохранить изменения отдельным коммитом с понятным названием.
- Перед публикацией проверить, что документы актуальны.
