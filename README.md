# Банковское приложение: история и переводы

Учебный проект посвящён банковскому приложению, в котором пользователь может посмотреть историю операций и выполнить перевод между счетами. В репозитории собраны основные требования, описание работы приложения, тесты и информация по организации проекта.

## Структура папок

```text
project_IS/
├── docs/          # требования и описание архитектуры
├── src/           # описание логики приложения
├── tests/         # примеры проверок
├── management/    # план и распределение работы
└── README.md      # описание проекта
```

## Как использовать проект

Это учебный репозиторий с документацией к проекту. Для ознакомления откройте `docs/requirements.md`, `docs/architecture.md`, `src/transfer_flow.md` и `tests/test_cases.md`. Это не настоящее банковское приложение: реальные платежи и подключение к банковским счетам здесь не выполняются.
