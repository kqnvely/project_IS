# Требования к банковскому приложению

## Назначение

Приложение нужно для просмотра операций по банковскому счёту и выполнения переводов между счетами. В учебной версии описывается логика работы, без подключения к настоящему банку.

## Основные требования

- **REQ-01. Вход.** Пользователь должен входить в приложение по логину и паролю.
- **REQ-02. История.** Пользователь должен видеть список своих операций.
- **REQ-03. Детали операции.** При выборе операции должны отображаться дата, сумма, тип операции и её статус.
- **REQ-04. Перевод.** Пользователь должен иметь возможность указать счёт получателя и сумму перевода.
- **REQ-05. Проверка перевода.** Перед подтверждением приложение должно проверить, что сумма больше нуля и на счёте хватает денег.
- **REQ-06. Результат.** После подтверждения пользователь должен увидеть результат перевода, а операция должна появиться в истории.

## Ограничения учебной версии

Приложение не подключается к реальным банковским счетам и не отправляет настоящие деньги. Данные используются только для демонстрации и проверки логики.
