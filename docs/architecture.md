# Архитектура банковского приложения

Учебное приложение можно разделить на три основные части.

## 1. Интерфейс пользователя

Здесь находятся экраны входа, истории операций и переводов. Пользователь вводит данные и получает сообщения о результате.

## 2. Основная логика

Эта часть проверяет введённую сумму, наличие денег на счёте и данные получателя. Если проверки пройдены, она оформляет учебную операцию и передаёт её на сохранение.

## 3. Хранение данных

Здесь хранятся пользователи, счета и история операций. В реальной системе доступ к таким данным должен быть защищён.

## Пример работы

Пользователь нажимает «Перевести» -> интерфейс передаёт данные основной логике -> выполняются проверки -> результат сохраняется -> новая операция появляется в истории.

## Связь с требованиями

- Вход относится к интерфейсу и проверке пользователя.
- Просмотр истории получает операции из хранилища.
- Перевод проходит через основную логику и после успешной проверки сохраняется в истории.
